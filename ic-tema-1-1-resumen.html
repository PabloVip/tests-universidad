1. Frameworks y librerías de Deep Learning

Mapa de frameworks (niveles de abstracción)

NivelEjemplos
Alto nivel / interfacesKNIME, Keras, Gluon, H2O, TensorLayer

Idea clave: los frameworks se apilan en capas. Keras es una capa de alto nivel; TensorFlow, PyTorch, etc. son el motor; y casi todos usan CUDA + cuDNN para ejecutar en GPU NVIDIA.

TensorFlow v2

  • Gratuito y de código abierto, bajo el paraguas de Google.
  • Pensado para científicos, ingenieros e investigadores, no solo informáticos.
  • Calcula las derivadas (gradientes) de cualquier función → ideal para la backpropagation.
  • Funciona en CPU y, sobre todo, en hardware paralelo masivo: GPU y TPU.
  • Distribución automática cuando hay varias máquinas disponibles.
  • Los programas se pueden exportar a otros entornos: C++, JavaScript o TF Lite (móvil y embebido).
  • AlphaZero (ajedrez y Go) está implementado con TensorFlow.

Keras

  • Código abierto; su principal autor es François Chollet (ingeniero de Google), que ha escrito libros para Python y para R.
  • Diseñado para reducir la carga cognitiva:
    • API coherentes y sencillas.
    • Mínimo número de acciones para los casos de uso comunes.
    • Mensajes de error claros y accionables.
    • Sirve para perfiles de nivel muy alto y muy bajo: equilibrio entre facilidad y flexibilidad.
    • Muchas herramientas: es mucho más que una librería.
  • Lo usan Google, Netflix, Uber, CERN, NASA…

Alternativa: PyTorch

  • Lanzado en 2016 por Facebook (hoy Meta).
  • Framework preferido por los investigadores universitarios (academia).
  • El gráfico de Google Trends de los apuntes muestra cómo el interés por PyTorch fue creciendo hasta alcanzar a TensorFlow hacia 2020.

2. Entornos de desarrollo

Entorno local

  • Python ≥ 3.10
  • Anaconda (distribución y gestor de entornos y paquetes)
  • CUDA (plataforma de cómputo en GPU de NVIDIA)
  • cuDNN (librería de NVIDIA para redes neuronales profundas sobre CUDA)
Importante: las versiones de Python + TensorFlow + CUDA + cuDNN tienen que ser compatibles entre sí. Consulta la tabla oficial de combinaciones probadas en la documentación de instalación de TensorFlow antes de instalar.
Fuera de los apuntes: a partir de TensorFlow 2.11 ya no hay soporte de GPU en Windows nativo; en Windows se usa WSL2. En Linux, pip install tensorflow[and-cuda] instala también las librerías de CUDA.

Hardware

Una GPU de NVIDIA es entre 10 y 100 veces más rápida que una CPU multinúcleo para Deep Learning.
