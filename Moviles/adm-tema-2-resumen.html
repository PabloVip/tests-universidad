1. ¿Qué es Kotlin?

Características (según apuntes)

  • Lenguaje moderno creado por JetBrains (2011).
  • Totalmente interoperable con Java: puede usar librerías y código Java.
  • Oficial para desarrollo Android desde 2017 (según Google).
  • Compila a JVM, pero también a JavaScript y nativo (Kotlin/Native).
  • Sintaxis simple, segura y expresiva → menos código, menos errores.
  • Null safety: seguridad frente a nulls para evitar errores comunes.
  • Soporta programación funcional y orientada a objetos.
  • Compatible con frameworks modernos (Spring, Compose, etc.).
  • Usado en Android, backend, web y multiplataforma (Kotlin Multiplatform).
Idea clave: menos código que Java, interoperable al 100% y oficial en Android. Si te preguntan “¿por qué Kotlin?”, responde: interoperabilidad + null safety + oficial Android 2017 + multiplatform.

3. Variables: var / val y tipos

var vs val + interpolación $

  • var: variable que puede cambiar de valor.
  • val: variable de solo lectura (como final).
  • Para referenciarlas en strings se usa $ y ${} para expresiones.
fun main() {
  val nombre = "Primoz Roglic"
  val numero = 1
  var posicion = 100

  println("El corredor $nombre (numero: $numero) ocupa la posicion $posicion.")
  posicion = 2
  println("El corredor $nombre (numero: $numero) ocupa la posicion $posicion.")
  // numero = 11 // ERROR: val no se puede reasignar
}
Error típico de examen: intentar reasignar un val. Falla en compilación.

Ejercicio de apuntes: crea variables nombre, equipo, número y posición que muestren: “El corredor Carlos Rodriguez (numero:11) del equipo Ineos ocupa la posición 5.”

4. Colecciones: List, Set, Map

Idea general

ColecciónLecturaMutableCaracterística
List (ordenada)List<> / listOf()MutableList<> / mutableListOf()Admite duplicados, ordenada
Set (desordenada)Set<> / setOf()MutableSet<> / mutableSetOf()Solo elementos únicos
Map (clave-valor)Map<> / mapOf()MutableMap<> / mutableMapOf()Claves únicas, con valor

Listas

fun main() {
  println("===LISTAS===")
  val ciclistaSoloLectura: List<String> = listOf("Primoz Roglic",
    "Carlos Rodriguez", "Enric Mas")
  println(ciclistaSoloLectura)

  var ciclistas: MutableList<String> =
    mutableListOf("Juan Ayuso", "Carlos Verona", "Wout van Aert")
  println(ciclistas)
}
val o var con colecciones: los apuntes usan var ciclistas: MutableList. Lo habitual es val: la lista sigue siendo modificable (add, remove); val solo impide reasignar la variable a otra lista.

Conjuntos (Sets)

Los duplicados se eliminan automáticamente.

fun main() {
  println("===SETS===")
  val ciclistaSoloLecturaSet: Set<String> = setOf("Carlos Rodriguez",
    "Primoz Roglic", "Carlos Rodriguez", "Enric Mas")
  println(ciclistaSoloLecturaSet) // Carlos Rodriguez aparece 1 vez

  var ciclistasSet: MutableSet<String> =
    mutableSetOf("Juan Ayuso", "Carlos Verona", "Wout van Aert")
  println(ciclistasSet)
}

Mapas

fun main() {
  println("===MAPS===")
  val ciclistasEquiposMap: Map<String, String> =
    mapOf("Carlos Rodriguez" to "Ineos",
          "Primoz Roglic" to "Jumbo-Visma",
          "Enric Mas" to "Movistar")
  println(ciclistasEquiposMap)

  val ciclistasEdadMap: Map<String, Int> =
    mapOf("Carlos Rodriguez" to 22,
          "Primoz Roglic" to 33,
          "Enric Mas" to 28)
  println(ciclistasEdadMap)
}
Ojo, error en los apuntes: el ejemplo hace ciclistasEdadMap[1]. En un Map<String, Int> eso no compila (la clave debe ser String, no Int). Los Map se consultan por clave: ciclistasEdadMap["Carlos Rodriguez"] (dentro de un String, ${ciclistasEdadMap["Carlos Rodriguez"]}). Si la clave no existe, devuelve null.

5. Flujos de control

if / else (también como expresión)

val edad = 18
if (edad >= 18) {
  println("Eres mayor de edad")
} else {
  println("Eres menor de edad")
}

val mensaje = if (edad >= 18) "Adulto" else "Menor"

when (el “switch” de Kotlin)

val dia = 3
when (dia) {
  1 -> println("Lunes")
  2 -> println("Martes")
  3 -> println("Miércoles")
  in 4..5 -> println("Jueves o Viernes")
  else -> println("Fin de semana")
}

for

for (i in 1..5) println(i)          // 1 a 5 incluido
for (i in 10 downTo 1) println(i)   // regresiva
for (i in 0 until 10 step 2) println(i) // 0,2,4,6,8

val clasificacion: Map<String, Int> = mapOf(
  "Carlos Rodriguez" to 1,
  "Primoz Roglic" to 3,
  "Enric Mas" to 6)

for (ciclista in clasificacion) {
  if (ciclista.value == 1) {
    println("El ciclista ${ciclista.key} es el lider")
  } else {
    println("El ciclista ${ciclista.key} ocupa la posición ${ciclista.value}")
  }
}
Rangos: 1..5 incluye el 5, until lo excluye, downTo baja, step salta.

forEach / forEachIndexed

val frutas = listOf("Manzana", "Banana", "Pera")
frutas.forEach { fruta ->
  println(fruta)
}

val numeros = listOf(10, 20, 30)
numeros.forEachIndexed { index, valor ->
  println("Índice $index tiene valor $valor")
}

6. Funciones

Sintaxis base

fun nombreDeFuncion(parametros): TipoDeRetorno {
  // cuerpo
  return valor
}

// Ejemplo apuntes
import kotlin.random.Random

fun correrCarrera(): Int {
  var posicion = Random.nextInt(0, 190)
  return posicion
}

Funciones de una línea, Unit y lambda

  • Función de una sola expresión (los apuntes la llaman «in-line»): si el cuerpo es una única expresión se escribe con =. No confundir con la palabra clave inline de Kotlin, que es otra cosa.
  • Unit: sin retorno, como void en C/Java.
  • Lambda: función anónima { parametros -> cuerpo }, usable como valor o argumento.
// Expresión única ("in-line" en los apuntes)
fun asignarNumero(): Int = Random.nextInt(0, 190) // devuelve 0..189

// Unit (sin retorno)
fun saludar(nombre: String): Unit {
  println("Hola, $nombre")
}

// Lambda
val cuadrado = { x: Int -> x * x }
println(cuadrado(4)) // 16

// Lambda como argumento
fun operar(a: Int, b: Int, operacion: (Int, Int) -> Int): Int {
  return operacion(a, b)
}
val suma = operar(5, 3, { x, y -> x + y })
val suma2 = operar(5, 3) { x, y -> x + y } // trailing lambda (idiomático)
Random: Random.nextInt(0, 190) incluye el 0 y excluye el 190. Lambda al final: si es el último parámetro puede ir fuera de los paréntesis.

7. Clases y herencia

Clase básica (parecida a Java)

class Persona(val nombre: String, var edad: Int) {
  fun saludar() {
    println("Hola, soy $nombre y tengo $edad años.")
  }
}

val persona = Persona("Paquito", 75)
persona.saludar()

Herencia: open + override

  • Por defecto las clases son final (no heredables). Para heredar usa open.
  • No hay herencia múltiple de clases, pero sí de interfaces.
open class Persona(val nombre: String, var edad: Int) {
  open fun saludar() {
    println("Hola, soy $nombre y tengo $edad años.")
  }
}

class Ciclista(nombre: String, edad: Int) : Persona(nombre, edad) {
  override fun saludar() = println("Soy el ciclista $nombre")
}

fun main() {
  val ciclista: Ciclista = Ciclista("Dani", 45)
  val persona: Persona = Persona("Antonio Jesus", 65)
  ciclista.saludar()
  persona.saludar()
}
Ojo al heredar: si la clase hija recibe nombre y edad para pasarlos al padre, decláralos sin val; si pones val nombre en la hija, choca con la propiedad del padre y no compila.

8. data class, abstract e interface

data class

Clase para almacenar datos sin código repetitivo. Genera toString(), equals()/hashCode(), copy() y componentN() para desestructuración.

data class Ciclista(val nombre: String, val age: Int, val sprint: Int, val equipo: String) {}

fun main() {
  val ciclista = Ciclista("Dani", 33, 66, "UCAM")
  println(ciclista.toString())
  val ciclista2 = Ciclista("Claudio Chiapucci", 56, 66, "Carrera")
  println(ciclista.equals(ciclista2)) // false
  val ciclista3 = ciclista.copy()
  println(ciclista.equals(ciclista3)) // true
  val (nombre, _, sprint) = ciclista
  println(nombre)
  println(sprint)
}

Clases abstractas

  • No se pueden instanciar.
  • Obligan a que los hijos implementen los métodos abstract.
abstract class Animal {
  abstract fun sonido()
}

class Gato(val nombre: String, val edad: Int) : Animal() {
  override fun sonido() {
    println("El gato hace miau.")
  }
}

class Perro(val nombre: String, val edad: Int) : Animal() {
  override fun sonido() {
    println("El perro hace guau.")
  }
}

fun main() {
  val gato = Gato("Garfield", 10)
  gato.sonido()
  val perro = Perro("Scooby", 7)
  perro.sonido()
}

Interfaces

Un contrato: dice qué debe hacer una clase, sin imponer el cómo. Define métodos y propiedades a implementar; un método puede traer implementación por defecto (atacar()).

interface ParticiparCarrera {
  val nombreCarrera: String
  fun atacar() {
    println("El ciclista está atacando.")
  }
  fun sprintar()
}

// Persona debe ser open (ver apartado 7)
class CiclistaComp(
  nombre: String, val apellido: String,
  edad: Int, val equipo: String, val sprint: Int
) : Persona(nombre, edad), ParticiparCarrera {
  override val nombreCarrera: String = "Tour de Francia"
  override fun sprintar() {
    println("El ciclista $nombre $apellido está sprintando ($sprint) en el $nombreCarrera")
  }
}

9. Coroutines + ejercicios y referencias

Coroutines (idea)

  • Forma simple y eficiente de manejar tareas asíncronas / concurrentes.
  • Evitan threads complicados: el código asíncrono se escribe como si fuera secuencial.
