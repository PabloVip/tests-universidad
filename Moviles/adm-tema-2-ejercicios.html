Ejercicio 2

var / val e interpolación fácil

Con val nombre="Primoz Roglic", val numero=1, var posicion=100, muestra “El corredor Primoz Roglic (numero: 1) ocupa la posicion 100.”, cambia posicion a 2 y vuelve a mostrar. Intenta reasignar numero y observa el error.

fun main() {
    val nombre = "Primoz Roglic"
    val numero = 1
    var posicion = 100

    println("El corredor $nombre (numero: $numero) ocupa la posicion $posicion.")
    posicion = 2
    println("El corredor $nombre (numero: $numero) ocupa la posicion $posicion.")
    // numero = 11 // ERROR: Val cannot be reassigned
}
Clave: var cambia, val no. $var y ${expr} interpolan.

Ejercicio 7

Maps equipo y edad medio

Crea mapOf("Carlos Rodriguez" to "Ineos", ...) y otro de edades. Accede por clave (no por índice).

fun main() {
    println("===MAPS===")
    val equipos: Map<String, String> = mapOf(
        "Carlos Rodriguez" to "Ineos",
        "Primoz Roglic" to "Jumbo-Visma",
        "Enric Mas" to "Movistar"
    )
    println(equipos)

    val edades: Map<String, Int> = mapOf(
        "Carlos Rodriguez" to 22,
        "Primoz Roglic" to 33,
        "Enric Mas" to 28
    )
    // CORRECTO: por clave
    println("La edad de Carlos Rodriguez es: ${edades["Carlos Rodriguez"]}")
    // OJO apuntes: edades[1] NO compila (la clave es String, no Int)
}
Examen: se accede con map[clave], nunca por posición. edades[1] ni siquiera compila porque la clave es String. Si la clave no existe, edades["Otro"] devuelve null.

Ejercicio 9

when por día fácil

Con dia=3: 1 Lunes, 2 Martes, 3 Miércoles, 4..5 Jueves o Viernes, else Fin de semana.

fun main() {
    val dia = 3
    when (dia) {
        1 -> println("Lunes")
        2 -> println("Martes")
        3 -> println("Miércoles")
        in 4..5 -> println("Jueves o Viernes")
        else -> println("Fin de semana")
    }
}
Ejercicio 10

for + rangos + líder medio

Recorre 1..5, 10 downTo 1, 0 until 10 step 2. Luego recorre mapOf(Carlos->1, Roglic->3, Mas->6) e indica quién es líder (value==1).

fun main() {
    for (i in 1..5) println(i) // 1..5 incluido
    for (i in 10 downTo 1) println(i) // regresiva
    for (i in 0 until 10 step 2) println(i) // 0,2,4,6,8

    val clasificacion: Map<String, Int> = mapOf(
        "Carlos Rodriguez" to 1,
        "Primoz Roglic" to 3,
        "Enric Mas" to 6
    )
    for (ciclista in clasificacion) {
        if (ciclista.value == 1) {
            println("El ciclista ${ciclista.key} es el lider")
        } else {
            println("El ciclista ${ciclista.key} ocupa la posición ${ciclista.value}")
        }
    }
}
Rangos: .. incluye fin, until excluye, downTo baja, step salta.

Bloque 4 - Funciones y POO

Ejercicio 12

Funciones: normal, de una línea, Unit y lambda medio

Crea correrCarrera():Int con Random, versión de una sola expresión asignarNumero() (los apuntes la llaman «in-line»), saludar():Unit y operar() con lambda.

import kotlin.random.Random

fun correrCarrera(): Int {
    val posicion = Random.nextInt(0, 190)
    return posicion
}

// Función de expresión única (los apuntes la llaman "in-line").
// Ojo: no es lo mismo que la palabra clave `inline` de Kotlin.
fun asignarNumero(): Int = Random.nextInt(0, 190) // 0..189: el límite superior es exclusivo

// Unit: sin retorno (como void)
fun saludar(nombre: String): Unit {
    println("Hola, $nombre")
}

// Lambda como valor y como argumento
val cuadrado = { x: Int -> x * x }

fun operar(a: Int, b: Int, operacion: (Int, Int) -> Int): Int {
    return operacion(a, b)
}

fun main() {
    println(correrCarrera())
    println(asignarNumero())
    saludar("Dani")
    println(cuadrado(4)) // 16
    val suma = operar(5, 3, { x, y -> x + y })
    println(suma) // 8
    val resta = operar(5, 3) { x, y -> x - y } // trailing lambda: forma idiomática
    println(resta) // 2
}
Clave: Random.nextInt(0, 190) devuelve de 0 a 189. Si quieres posiciones de 1 a 190, usa Random.nextInt(1, 191). Cuando la lambda es el último argumento, se puede sacar fuera de los paréntesis.
Ejercicio 13

Clases, herencia y data class medio

Crea Persona, Ciclista:Persona con open/override, y data class CiclistaData con copy y desestructuración.

open class Persona(val nombre: String, var edad: Int) {
    open fun saludar() {
        println("Hola, soy $nombre y tengo $edad años.")
    }
}

class Ciclista(nombre: String, edad: Int) : Persona(nombre, edad) {
    override fun saludar() = println("Soy el ciclista $nombre")
}

data class CiclistaData(val nombre: String, val age: Int, val sprint: Int, val equipo: String)

fun main() {
    val ciclista = Ciclista("Dani", 45)
    val persona = Persona("Antonio Jesus", 65)
    ciclista.saludar()
    persona.saludar()

    val c1 = CiclistaData("Dani", 33, 66, "UCAM")
    println(c1.toString())
    val c2 = CiclistaData("Claudio Chiapucci", 56, 66, "Carrera")
    println(c1.equals(c2)) // false
    val c3 = c1.copy()
    println(c1.equals(c3)) // true
    val (nombre, _, sprint) = c1
    println(nombre)
    println(sprint)
}
Clave: sin open no hay herencia (final por defecto). data class da toString/equals/copy/componentN gratis. En Kotlin es más idiomático comparar con c1 == c3 que con equals. (Los apuntes usan age; en tu código mejor edad, coherente con Persona.)
Ejercicio 14

Ejercicio final apuntes: Estudiante medio

Clase Estudiante(nombre, nota) + función mostrarEstudiantes(lista) que muestre “aprobado” si ≥5 y “suspenso” si no. Pruébala con 3 alumnos.

class Estudiante(val nombre: String, val nota: Double)

fun mostrarEstudiantes(lista: List<Estudiante>) {
    for (e in lista) {
        val estado = if (e.nota >= 5) "aprobado" else "suspenso"

}

fun main() {

        Estudiante("Mario", 4.9),
        Estudiante("Dani", 5.0)
    )
    mostrarEstudiantes(clase)
}
Ejercicio 15

Clase abstracta Animal medio

Crea una clase abstracta Animal con el método abstracto sonido() y dos subclases, Gato y Perro, que lo implementen. Comprueba que Animal() no se puede instanciar.

abstract class Animal(val nombre: String, val edad: Int) {
    abstract fun sonido()
}

class Gato(nombre: String, edad: Int) : Animal(nombre, edad) {
    override fun sonido() {
        println("El gato $nombre hace miau.")
    }
}

class Perro(nombre: String, edad: Int) : Animal(nombre, edad) {
    override fun sonido() {
        println("El perro $nombre hace guau.")
    }
}

fun main() {
    val animales: List<Animal> = listOf(Gato("Garfield", 10), Perro("Scooby", 7))
    animales.forEach { it.sonido() }
    // val a = Animal("X", 1) // ERROR: Cannot create an instance of an abstract class
}
Clave: una clase abstracta no se instancia y obliga a sus hijas a implementar los métodos abstract. No hace falta marcarla open: las abstractas ya son heredables.
Ejercicio 16

Interfaz ParticiparCarrera difícil

Define la interfaz ParticiparCarrera con la propiedad nombreCarrera, un método atacar() con implementación por defecto y un método abstracto sprintar(). Haz que un Ciclista herede de Persona e implemente la interfaz.

interface ParticiparCarrera {
    val nombreCarrera: String
    fun atacar() {
        println("El ciclista está atacando.")
    }
    fun sprintar()
}

open class Persona(val nombre: String, val apellido: String, var edad: Int)

class Ciclista(
    nombre: String, apellido: String, edad: Int,
    val equipo: String, val sprint: Int
) : Persona(nombre, apellido, edad), ParticiparCarrera {
    override val nombreCarrera: String = "Tour de Francia"
    override fun sprintar() {
        println("El ciclista $nombre $apellido está sprintando ($sprint) en el $nombreCarrera")
    }
}

fun main() {
    val c = Ciclista("Carlos", "Rodriguez", 22, "Ineos", 80)
    c.atacar()   // usa la implementación por defecto
    c.sprintar()
}
Clave: se hereda de una clase y se implementan varias interfaces. Los parámetros que ya son propiedades en Persona se pasan sin val en Ciclista; si repites val nombre el compilador da error porque ocultarías la propiedad del padre.
